# Результаты хакатона

Команда: **жи ши пишется через**. Формат: **Appendix Results JSON 1.0**.

- `dev/results.json` формируется из официального DEV: 60 чатов и 5 звонков.
- `prod/results.json` до выдачи контрольного набора содержит пустой шаблон. Это **не готовая сдача PROD**. После обработки он должен содержать ровно 10 исходных ID, включая ошибки.

Не подставляйте демонстрационные ID и не копируйте синтетические обучающие примеры в результаты DEV/PROD.
