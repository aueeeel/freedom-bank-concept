# Результаты команды «жи-ши пишется через»

Формат приложения к гайду: schema_version 1.0. Только оператор; исходные веса 10/15/20/20/15/15/5. evidence_turns — индексы с 1 по полному транскрипту. Грубый флаг не обнуляет итог.

- prod/results.json: 10 FBroker, все с финальной оценкой после независимого разбора ассистентом Codex. Локальная Qwen3.5-4B завершила 8 из 10 диалогов; два ответа оборвались на JSON. Итоговый mode=hybrid явно включает экспертный пересмотр, а не выдаёт все записи за успешный вывод локальной модели. Подробности: ../docs/submission-audit.json.
- dev/results.json: 65 записей; 7 сохранённых результатов модели, 58 status=error. Неполный экспорт опубликован по прямому выбору пользователя. Пользовательские эталоны не выданы за новый прогон модели.

SWAP сохранён локально отдельно и не оценивался. Его нет в prod. Сырые клиентские транскрипты, SQLite и секретные URL в репозитории не публикуются.
