# Freedom CQA — прототип без подключения ИИ

Страница: `/check.html`. Пункт «Проверка» заменяет «Возможности» в общей навигации.
Главная сохраняет видео `neon-water-waves-v2.mp4`. На странице сотрудников и в CQA
работает адаптированный Wave Mesh из предоставленного пользователем компонента.
Цвета согласованы с чёрно-зелёным интерфейсом, шрифт — Montserrat.

## Что работает без ключа

- Импорт JSON с `data.records`, массива записей или одной записи с `transcript`.
- Обычная загрузка: один файл — один диалог. Бот, клиент и оператор остаются участниками общего транскрипта, а не отдельными проверками. Соседний режим «Набор диалогов» сохраняет отдельные чаты большого датасета; части с одинаковым `conversation_id` объединяются и в нём. Несколько файлов одного разговора можно отправить вместе в обычном режиме.
- TXT с ролями и временем, CSV с колонками `timestamp,speaker,text`, SRT, VTT,
  текстовые PDF. PDF.js загружается отдельно только для PDF. Сканы требуют OCR.
- Импорт до трёх файлов за один раз, до 20 МБ каждый. До 1000 диалогов в наборе,
  5000 реплик на диалог, 100 страниц PDF, 2 миллионов символов на текстовый файл.
- Роли `operator`, `client`, `bot`, `system`; неизвестная роль показывается явно
  и может быть исправлена пользователем. Исходные временные метки сохраняются.
- Загрузка и прослушивание аудио. Готовый транскрипт можно прикрепить к пустой
  записи. Нажатие на временную метку переходит к этому моменту аудио.
  Для ISO 8601 позиция вычисляется относительно первой реплики.
- Восемь исходных критериев из выданного чек-листа. Ручная оценка, обоснования,
  привязка доказательств к репликам, переход к контексту.
- Нормализация числовых шкал по весу; исключение N/A и перераспределение весов;
  округление до двух знаков. Грубые нарушения — отдельный флаг, без обнуления балла.
- Изменение и добавление критериев, веса, шкалы и доступности N/A через интерфейс.
- Апелляция и решение проверяющего с причиной. Исходная оценка остаётся отдельной
  от решения, итог пересчитывается. После апелляции исходный ответ заблокирован.
- Явное сохранение текущего пространства в localStorage и экспорт JSON.
  Экспорт содержит ID реплик, чтобы сохранить связь с доказательствами.

Оценщик ИИ пока не подключён. По явной команде руководителя транскрипт, снимок критериев и оценки сохраняются в защищённую историю сотрудников в Supabase; исходный аудиофайл туда не отправляется. Аудиофайлы существуют
как временные object URL в сеансе браузера; после перезагрузки их надо прикрепить
повторно. Текст и оценки сохраняются только при нажатии кнопок сохранения.

Демонстрационный диалог вымышленный; его оценка подготовлена заранее и явно
подписана. Текстовые ответы помощника о текущем состоянии формируются локально
и не выдаются за вывод языковой модели. Автоматической оценки и распознавания
речи в этой версии нет — ключ отложен по просьбе пользователя.

## Подключение ИИ позже

`qa-config.js` содержит только публичные URL двух будущих серверных маршрутов.
Они сейчас пусты; запросов к моделям нет. Ключи нельзя добавлять в этот файл.

`analysisEndpoint` принимает POST JSON `{conversation, checklist}`. Реплики содержат
`id`, `timestamp`, `speaker`, `text`. Ответ — `{evaluations: {[criterionId]:
{value, reason, evidence: [turnId]}}}`. Значение — `yes`, `no`, `na` или допустимая
ступень числовой шкалы. Клиент проверяет ответы и существование реплик, а баллы
всегда вычисляет сам. Ответ модели не может содержать произвольный HTML.

`transcriptionEndpoint` принимает multipart `audio` и возвращает
`{transcript: [{timestamp, speaker, text}]}`. Диаризация должна действительно
разделять участников; неизвестные голоса нельзя автоматически объявлять оператором
или клиентом без основания. Возвращённый транскрипт проходит общий валидатор.

Маршруты должны находиться на домене сайта. До включения надо реализовать
сервер, ограничения запросов, проверку доступа и при необходимости прямую
загрузку крупных файлов в приватное хранилище. Секреты хранятся только на сервере.
Содержимое диалогов следует передавать модели как данные, а не инструкции.

## Проверки

`npm test` проверяет веса и шкалы, N/A, отсутствие итога при неполной оценке,
отдельный флаг грубых ошибок, историю апелляции, валидацию критериев,
JSON датасета, TXT/SRT/CSV, неизвестные роли и ISO-время.

В браузере проверены подготовленный пример, исходный итог 85,38, апелляция
с перерасчётом до 70, переход к реплике, сохранение после перезагрузки,
импорт набора RU/EN, PDF, аудио длительностью 2 секунды и переход к отметке 00:01.
